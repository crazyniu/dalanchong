# 大懒虫浏览器插件

面向 Chromium 浏览器的视频工具与达人邀约工作区。使用浏览器现有登录会话处理平台操作，工作区数据保存在当前浏览器，所有功能均需有效激活。

> 当前版本：`0.3.6` · 最低 Chromium：`116` · Manifest V3
>
> 本地自动测试与 ZIP 构建已提供。真实激活、平台邀约及不同浏览器发行版仍须按[验收清单](docs/TESTING.md)验证，不能把构建成功视为生产验收。

## 功能

### 视频工具

- 网页完整视频捕获、列表预览与画质选择。
- 抖音详情视频解析、分享链接解析及批量处理。
- 快手详情页视频格式识别。
- 浏览器原生下载队列、任务进度与已下载记录。
- 支持页面的商品/达人关联视频、筛选、复制与批量下载。

### 达人邀约

- 抖音、快手来源标签页识别与账号状态核对。
- 根据来源页面实际筛选结果采集达人，按平台及账号隔离。
- 昵称/ID 搜索、性别、粉丝范围、来源及记录状态筛选。
- 跨页选择、全筛选选择、CSV 导出、主页入口和复制。
- 商品、话术、联系方式、发送间隔和数量上限配置；可显式保存本机账号配置。
- 采集与邀约任务分别停止；持久任务摘要、日志分页与导出。
- 发送前事务去重；结果不确定时停止并显示待核实，人工核实前不自动重发。

## 安装与激活

1. 下载无签名 ZIP 并解压，或获取本仓库源码。
2. 打开浏览器扩展管理页，启用开发者模式，选择「加载已解压的扩展程序」。
3. 选择 ZIP 解压目录，或源码中的 `browser-extension/`。
4. 点击工具栏中的大懒虫图标，完成激活。
5. 在浏览器登录平台，进入插件工作区选择已打开的来源页。

不同 Chromium 浏览器的安装政策可能不同；CRX 签名不等于可以在所有浏览器中直接安装。正式签名发行参见[构建与发布](docs/EXTENSION_RELEASE.md)。

未激活时只显示激活引导，网页不显示业务浮层。授权失效会停止任务、收起网页组件；重新激活不会自动恢复已经停止的邀约。

首次授权握手前不读取网页业务响应。若未识别到首屏视频或列表，请回到来源页刷新、重新播放或重新操作筛选后重试。插件不会自动刷新页面，以免丢失用户输入。

## 使用邀约工作区

1. 打开支持的达人来源页，登录并应用搜索或筛选。
2. 在「达人邀约」选择该标签页并准备来源，确认账号与就绪状态。
3. 点击采集，在本地列表筛选并选择目标达人。
4. 填写商品及邀约配置，检查范围后明确点击开始邀约。
5. 查看任务、日志与结果。遇到待核实记录，先在平台核实真实结果再处理。

同一浏览器配置中的标签页共享平台 Cookie，不代表独立账号会话。任务运行时不要切换平台账号；页面导航或账号变化会使任务停止。清理邀约历史会移除本机去重限制，可能导致再次邀约。

## 数据与权限

- 达人、邀约记录、任务日志及主动保存的账号配置使用本机 IndexedDB；最多保存 `10000` 位达人，不提供浏览器间同步。
- 激活码与安装标识保存在扩展本地存储，不写入日志或仓库。安装标识不是硬件身份，不承诺防克隆。
- 授权与规则服务会收到激活码、安装标识及最小规则摘要，例如商品 ID、资格状态、联系方式是否完整、视频格式元数据。
- 规则请求不包含达人名单、联系方式正文、话术正文、平台 Cookie、视频 URL 或视频文件。用户发起邀约时，浏览器向相应平台提交必要业务内容。
- `scripting` 用于授权后的页面适配；`webRequest` 用于媒体识别；`downloads` 用于下载；`storage` 用于本机数据；`tabs` 用于来源定位；`alarms` 用于授权复核。
- 网页访问范围用于支持当前网页的视频识别和平台适配。未激活的 frame 引导脚本只查询授权，不采集页面内容。

仅对你有权处理的内容和账号使用本工具，并遵守平台规则及接收方意愿。没有自动绕过验证码、自动解绑激活码或隐式恢复发送。

## 本地开发

环境：Node.js 24+，pnpm 11.15.1。

```sh
pnpm install --frozen-lockfile
node --test tests/*.test.mjs
pnpm package:extension --zip-only
```

输出位于 `dist-release/browser-extension/`。压缩处理只作用于构建副本，不改写可读源码。测试默认不使用真实激活码、不访问平台、不发送邀约。

```text
browser-extension/    扩展页面、worker、网页适配与本机存储
scripts/              构建与打包
.github/workflows/    PR 验证和签名发布
tests/               无账号自动测试
docs/                发行与验收说明
```
