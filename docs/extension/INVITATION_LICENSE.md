# 插件激活与授权错误处理

## 激活步骤

1. 点击浏览器工具栏的插件图标，在激活界面输入大懒虫激活码。
2. 点击激活；只有服务器确认有效且本地保存成功后才开放插件功能。
3. 已保存码可点击重新验证。验证不绑定、不换绑，也不会自动变成激活。
4. 提示已绑定其他安装时，联系管理员按现有方式解绑，再主动激活。插件不会自动解绑。

插件不需要管理员密码、JWT 或服务端密钥。授权请求使用固定 `app_id: dalanchong`，接口为 `https://dabudian.top/functions/v1/license-api/activate` 和 `/verify`。

## 本地保存与有效期

插件首次初始化生成当前浏览器配置目录的持久安装 UUID，安装标识与成功激活的码保存在扩展本地，不使用同步存储。UUID 不是硬件身份；复制整个浏览器配置目录可能复制标识，本方案不承诺防克隆或防破解。

业务数据保存在本机 IndexedDB，不通过授权接口同步。授权请求只包含软件标识、激活码和安装标识；不把码放进 URL、日志、页面广播或错误详情。

启动时验证已保存码，后台每 10 分钟刷新。有效状态仅保存在后台内存，最长不超过 10 分钟及服务器授权到期时间。断网、解绑、禁用、过期或校验失败时停止插件业务操作；恢复有效后不会自动重启已停止任务。停止任务本身不需要有效授权。

## 常见错误

| 提示 | 处理 |
| --- | --- |
| 请输入激活码 | 输入有效码并主动激活 |
| 激活码无效 | 检查是否属于大懒虫及输入是否正确 |
| 已绑定其他安装 | 联系管理员解绑后再激活 |
| 安装已解绑 | 确认换绑安排后主动激活，不会自动抢回绑定 |
| 安装已禁用 | 联系管理员处理 |
| 激活码过期 | 使用有效激活码 |
| 授权服务连接失败 | 检查网络后重新验证；不会离线放行 |
| 本地授权无法保存 | 检查浏览器存储是否可用后重试 |

输入错误替换码不会覆盖原有已保存码。验证当前码失败会立即撤销内存有效状态，但不删除保存的码，便于用户后续重新验证。

## 云规则接口

后台 `inviteLicense.rules(action,input)` 调用固定 `POST https://dabudian.top/functions/v1/extension-rules`。只有 `invite.validate`、`invite.decide`、`video.rank` 三个动作，不能选择任意 URL 或服务函数。

调用先完成授权初始化，再检查有效内存状态；凭据只由后台从本地读取并填入 HTTPS 请求。页面不持有激活码。请求最长 15 秒，不自动激活，不自动重试，不用离线替代规则。

请求只发送动作需要的摘要：

- 邀约配置：平台、商品 ID、话术字数、是否填写联系方式、间隔及数量上限。
- 邀约判断：平台、商品 ID、资格布尔/数值摘要、可带商品 ID、联系方式是否完整。
- 视频格式排序：候选序号、清晰度标签、高度和更新时间，不发送视频 URL。

不发送联系方式原文、话术正文、Cookie、平台令牌、达人身份或平台原始响应。返回的商品 ID、固定发送路径/默认字段与视频排序索引会校验后再交给调用者。

HTTP 403 授权拒绝会使内存状态失效。400 参数错误、429 频率限制只停止当前规则操作，不删除激活码或无故撤销有效状态。服务未部署、断网、超时、格式不符会明确提示“云规则服务不可用”，不会当作规则通过。

插件所有业务功能统一要求有效激活；未激活时仅显示激活界面，不显示网页业务浮层。失效后停止在途探测、插件下载和邀约任务，撤下业务界面。多格式视频推荐通过 `video.rank` 获取排序，云服务不可用不使用本地替代排序。

## 模块接口与验证状态

后台独占 `inviteLicense`：`initialize()`、`activate(code)`、`verify()`、`status()`、`requireValid(scope?)` 和 `rules(action,input)`。状态只包含 checked、valid、reason、message、expiresAt、hasCode、principalId；principalId 是安装标识供本地数据隔离，不是账号登录证明。错误只返回固定说明，不含码或服务原文。

本地自动检查使用模拟授权、平台响应与 IndexedDB 验证，详见[验证与验收](../TESTING.md)。这些检查不代表真实激活、云规则服务部署或平台功能已验收。

后台统一通过 `license-background.js` 初始化和每 10 分钟校验，以 `LICENSE_CHANGED` 通知界面与任务。失效期间创建的历史数据保留；中断任务需用户重新开始，不会因授权恢复自动续跑。
