# 达人邀约

网页工作区提供来源准备、采集、达人选择、筛选与 CSV 导出、邀约配置、任务状态、停止和本地记录。所有开始操作都需要用户明确点击；停止不要求授权仍然有效。

## 使用顺序

1. 点击插件「更多」，从顶部导航选择「抖音达人邀约」或「快手达人邀约」，进入对应平台并使用当前浏览器登录会话。
2. 从工具栏插件图标激活后，网页底部显示可拖动的邀约工具栏。
3. 在平台页面应用搜索或筛选，点击工具栏采集；打开「邀约达人」查看当前账号列表。
4. 筛选或勾选达人，打开配置侧栏，填写商品、话术和联系信息后明确开始邀约。未勾选时使用当前筛选的未处理达人；导出有勾选时只导出所选。
5. 查看记录；待核实表示无法确定平台是否已经发送，请先人工确认，不要重复提交。

来源支持抖音达人广场、意向带货达人、同行参考、达人榜，以及快手达人广场、同行参考、达人榜。

快手同行合作参考按网页筛选读取店铺列表，再逐店读取合作达人，以达人 ID 去重保存，店铺名称作为来源。网页打开某家店的合作达人列表时，可采集该店当前列表。页面获得授权后即启动请求监听，工作区接入已有观察结果，不等待工具栏显示后才开始监听。

每位快手达人补采近 7/30 日直播场均、短视频销售额，业务请求保持 1 秒间隔。账号在页面准备时读取，采集过程中使用网页观察到的账号状态，不为每个指标请求重复联网查询账号。工具栏数量使用当前账号的数据库计数。

## 数据与任务

达人与邀约记录按当前安装、平台及平台账号隔离，保存在 IndexedDB；同一浏览器最多保存 10000 位达人。未保存的配置草稿与选择仅保留在浏览器会话内存，登录返回后只为相同授权主体、平台和账号恢复；使用“保存配置”后，商品、话术及联系方式按当前平台账号保存在本机 IndexedDB。平台登录会话由浏览器管理。

列表筛选按平台与账号保存在本机，支持邀约状态、性别、粉丝数及销售额范围；抖音另有带货类型。销售额使用平台披露的区间，金额范围筛选要求整个区间落在所选范围内，表格和 CSV 以万元显示。

采集期间来源网页显示遮罩并暂停交互，工具栏仍可停止采集；停止采集不会停止邀约。采集结束或停止后收起本次终端，不恢复已结束任务的终端；达人、邀约记录和错误日志保留。

任务绑定来源文档与平台账号。页面导航、账号变化、授权失效或任务中断会停止新请求。发送前必须完成本地事务记录；平台请求失败后按任务规则等待并重试同一条记录，抖音重试前重新读取资格与商品。停止前尚未发送的占位记录会释放；终止后的不确定发送结果保留待核实。浏览器退出或后台重启不会自动恢复发送。

授权及规则请求只使用完成相应操作所需的参数，不上传达人名单、话术、联系方式、平台 Cookie 或视频文件。

## 当前验证范围

真实平台采集/邀约、真实激活、规则服务可用性及端到端流程尚未验证。不要把本地构建成功当成真实账号验收通过。

人工核实仅适用于待核实记录，且该账号没有运行中的任务。确认“未邀约”记为已跳过，保留历史与去重；确认成功记为已邀约。核实不改变原发送时间，删除达人不会删除其邀约历史。
