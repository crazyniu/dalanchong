# 验证与验收

浏览器功能由用户验收。未明确要求时不运行测试、lint、验证构建、界面自动化或截图。

## 按需离线检查

```sh
pnpm check
pnpm test
pnpm package:extension --zip-only
```

现有测试使用本地模拟的浏览器接口或包文件，不代表真实网站与账号下载已通过。

## 用户验收范围

- 加载或重新加载插件后刷新网页，检查图标、弹窗视频列表与「更多」入口。
- 视频捕获覆盖网页和 iframe，排除音频、分段、播放清单与 blob。
- 抖音、快手详情按钮、画质选择、原片解析与分享链接批量解析。
- 网页居中预览、播放控制、关闭、复制地址及视频管理页。
- 单条、全部、所选下载及进度；清空捕获列表保留已下载文件。
- 电商页面的视频复制、筛选、商品/达人关联视频及下载。
- 打包附件、固定签名 ID 和 Chromium 安装政策。
