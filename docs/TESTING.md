# 验证与验收

## 本地自动检查

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm package:extension --zip-only
```

自动检查使用模拟授权和平台响应，不调用真实平台、不发送邀约，不说明生产服务已部署。测试包括授权消息与失效取消、网页注入生命周期、规则参数与响应约束、发送去重与停止竞态、IndexedDB 隔离和 10000 达人上限。可选的本地规则实现联调默认跳过。

## 浏览器人工验收

在单独的 Chromium 116+ 浏览器配置中加载 `browser-extension/`，勿用重要生产账号直接批量发送。

1. 未激活时，插件弹窗只显示激活引导；直接打开管理、预览、邀约页同样锁定。网页不得显示工具面板。
2. 完成有效激活后确认原有视频捕获、预览、详情画质、批量解析、下载、商业列表增强恢复。
3. 授权撤销或到期时，网页浮层收起、队列停止、旧异步结果不能在重新激活后继续执行。已提交至平台的请求无法撤回，应检查其真实结果。
4. 首次授权握手前不读取页面业务响应，因此极早的首屏请求可能未观察到。回到来源网页刷新或重新操作筛选后重试；插件不自动刷新网页以免丢失输入。
5. 两个平台分别验证来源准备、账号切换、筛选后采集、搜索与分页、CSV、配置本机保存、任务日志和停止。一个浏览器配置中的标签页共享平台登录状态，不代表独立账号会话。
6. 经账号所有者明确同意后，以极少量实际对象验证邀约。检查商品、联系信息、去重、任务结束与待核实流程，不能把模拟响应当作平台发送成功。
7. 核实待核实记录前须先查平台；清理邀约记录会移除本机去重限制，存在重复发送风险。

## 尚未完成的真实环境验证

真实激活、平台接口和邀约发送、规则服务生产可用性、完整浏览器交互与不同浏览器发行版兼容性仍须按以上步骤验收。无签名 ZIP 构建不代表 CRX 或商店版本已发行。


## 0.3.7 入口与网页工作区回归

- 插件弹窗仅“更多”进入统一工作页；导航及右键分抖音、快手，对应平台网址且不自动发送。
- 邀约列表仅在平台来源页内嵌显示，直接打开 invite.html 返回插件入口；有效授权不重复显示激活码表单。
- 日志、记录切换与关闭收起保留内嵌文档；筛选不清选择；当前筛选与无历史记录取交集，不替换筛选条件。
- 草稿、所选名单使用会话内存并验证真实账号 scope；打开配置核算可邀约人数，登录返回不会自动采集或发送。
- 未登录或列表未就绪禁止采集；常驻完整进度计数与重试倒计时；不同来源导航停止旧任务。
- 回跳控件只记同标签页固定平台来源，显式点击前复核当前 URL 与授权，禁止跨平台或任意 URL。
- 本地模拟与 ZIP 检查不能代表平台验收。云图形 Chromium 已打开开发者模式，实际点击加载扩展后显示“Extension installation is blocked by policy.”，因此当前没有插件真实装载/平台视觉验收结果。真实账号登录及少量邀约仍需用户授权并验证。


## 0.3.8 数据工作区回归

- 精确来源下拉来自当前账号完整数据；昵称/ID/来源搜索与结果状态筛选相互取交集。
- 实时活动最多 200 条，向上阅读不自动拉回，回到底部恢复跟随；切账号清空，晚到请求不可显示旧数据。
- 删除有选择时仅所选，无选择时明确确认当前账号全部达人含筛选外；保留历史防重复，运行任务期间不允许删除。
- 平台复制值遵循昵称/平台ID，缺值禁用；主表仅核心指标，其余真实数据可展开详情，CSV仍完整。
- 以上新增行为有模拟回归与构建验证，真实平台登录、页面CSP和发送仍需实际浏览器验收。
