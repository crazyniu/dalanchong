# 验证与验收

测试与浏览器验收由用户负责。未明确要求时不运行测试、lint、验证构建、界面自动化或截图。以下命令和清单用于按需检查，不是默认交付步骤。

## 本地自动检查

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm package:extension --zip-only
```

现有自动检查使用模拟授权、平台响应和 IndexedDB，不调用真实平台、不发送邀约。模拟响应不能证明真实平台、账号或云规则调用可用。

## 浏览器验收

1. 未激活时，popup、管理和设置页面只显示激活引导，平台网页没有业务浮层。
2. 激活后从「更多」打开两平台入口，检查实际页面底部工具栏、拖动、前后退、主页及重新加载。
3. 在支持的来源页面筛选后采集，检查遮罩、实时终端、列表数据及独立停止采集；采集结束或停止后终端收起，历史数据保留。
4. 检查表格、筛选 Dialog、配置 Sheet、记录和错误日志：字号、间距、字段、关闭按钮、键盘焦点与滚动。弹层只能通过明确按钮关闭。
5. 检查账号内筛选保存、性别、粉丝范围、销售额口径与完整金额区间、抖音带货类型，以及跨页选择、CSV、删除和复制。
6. 检查邀约配置、任务计数、重试倒计时和停止；真实发送只由用户明确执行。停止前未发送的占位记录释放；待核实记录必须先查平台结果。
7. 检查切换平台账号、页面导航、后台重启与授权失效时任务停止和界面清理；恢复授权不会自动开始任务。
8. 检查原有视频捕获、预览、画质选择、批量解析、下载、设置及本地记录。

同一浏览器配置的标签页共享平台 Cookie。名单、记录、日志及已保存配置使用本机 IndexedDB；清理邀约历史会移除相应去重限制。首次授权握手前不读取页面业务响应，必要时由用户重新筛选或刷新来源页。
