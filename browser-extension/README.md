# 视频工具

所有功能需要有效激活。点击浏览器工具栏插件图标完成激活；授权失效时功能停止，页面只显示激活引导。

## 捕获与预览

插件在 HTTP/HTTPS 页面及 iframe 中识别真实请求或播放的完整视频。弹窗显示当前浏览器配置目录内捕获的视频，可选择画质、复制地址、预览、批量下载或清空列表。音频、播放清单、视频分段和 blob 地址不会作为完整视频下载。

预览在当前页面显示，管理页也提供播放器。视频保持原比例，通过关闭按钮退出。

## 详情页下载与溯源

抖音和快手视频详情提供原画及当前清晰度按钮。悬停、聚焦或点击时读取对应文件信息；未取得完整大小时显示大小未知。切换作品或画质后重新核对资源，不把封面当视频。

视频溯源支持输入多条抖音链接或分享文案，使用当前浏览器已登录的平台页面解析。需要先打开对应网页。解析结果可预览、复制及下载。

## 下载任务

批量下载由浏览器下载队列执行，同时最多处理 6 个文件。单个文件失败不阻塞其他文件。下载状态与错误在界面中展示；清空捕获列表不会删除用户已下载的文件。

授权失效会停止新增任务与插件管理的未完成下载，重新激活不会自动恢复发送或下载任务。

## 商业页面

支持页面中的列表增强、筛选、分页、选择、复制与关联视频功能见 [电商页面](COMMERCE.md)。设有店铺名称的浏览器配置目录可在网页显示名称浮标。

## 存储

媒体及下载运行状态保存在扩展会话存储，商业页面缓存保存在当前浏览器本地存储。不同浏览器配置目录的数据互相隔离。
